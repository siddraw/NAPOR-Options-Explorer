SOURCE STANDARD (non-negotiable)
ALLOWED as a citation: AP, Reuters, AFP, BBC, NPR, PBS, NYT, WSJ, Washington Post, Bloomberg, Financial Times, CBS, ABC, NBC, CNN, Al Jazeera, Axios, Politico, Times of Israel / Haaretz (note they are Israeli outlets), USNI News, Defense News, Breaking Defense, The War Zone, Stars and Stripes, official statements (CENTCOM, DoD, White House, Treasury/OFAC, UKMTO, UN, IAEA).
Iranian state media (IRNA, Tasnim, Press TV) is allowed ONLY to document what Iran CLAIMS, and must be labelled as a claim.
NOT ALLOWED as a citation: Wikipedia (any language), blogs, Substack, aggregators, regional content farms, tabloids (Daily Mirror, Daily Mail, Express, Sun), think-tank opinion pieces used for facts, social media.
Wikipedia may be used ONLY as a map to find the footnoted articles; the claim must then be re-confirmed in the cited outlet itself, and only the outlet is cited.
Never invent a URL or a quote: only report URLs that came from your search results or fetches. Mark each source seen="full text" if you read the article, or seen="snippet" if you only saw the search-result headline/snippet.
LINK RULE (approved 2026-10-28): an event counts only if it has at least one source with a working https URL from an allowed outlet or an official release. A report that only names an outlet, with no link, gets zero credit. An event with no linked source is excluded from every count, rate, backtest and recount, in all five theaters.
If you cannot find a credible outlet for a claim, the verdict is not_confirmed. Do not fill the gap with a weaker source.
